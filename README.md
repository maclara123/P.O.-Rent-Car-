# P.O. Rent Car x UNC 

Projeto acadêmico desenvolvido em parceria com uma empresa local de locação de veículos, com o intuito de solucionar um problema real de gestão. A proposta do sistema é facilitar a organização dos processos de locação, principalmente nas etapas de check-in e check-out dos veículos, tornando o controle mais eficiente, padronizado e seguro.

# Objetivo do Projeto 

Desenvolver um sistema para auxiliar uma locadora de veículos na organização de seus processos internos, permitindo o cadastro de clientes e veículos, o controle de locações, a realização de vistorias com fotos e a utilização de QR Codes nos veículos, a fim de facilitar o acesso às informações e às funcionalidades relacionadas ao aluguel.
